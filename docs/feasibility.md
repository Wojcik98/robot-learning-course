## Simulator reset seed correction (2026-10-01)

The LeRobot LIBERO wrapper passes `seed=None` to LIBERO if a rollout calls `reset()` without a seed. LIBERO then calls `numpy.random.seed(None)`. This replaced the seed set by the course evaluator before reset. Two runs of the same SmolVLA model on development state 2 gave different success results. The corrected rollout path passes an explicit seed to the simulator reset. Two new state-2 runs then matched in success, step count, and clipped action count. The [diagnosis record](../artifacts/reference/smolvla/reset_seed_diagnosis.json) has the four outcomes.

The ACT Lab 3 suite and the earlier SmolVLA results remain records of their runs, but they used the old reset path. Do not use their success counts for a seeded cross-method comparison. Rerun the selected references with the corrected reset before a course comparison or release claim.
